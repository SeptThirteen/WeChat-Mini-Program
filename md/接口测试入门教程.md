# 接口测试入门教程（通用版）

> 适合零基础快速上手的接口测试入门指南，适用于任意后端项目（RESTful API）。

---

## 1. 什么是接口测试

接口测试是验证后端 API 是否符合预期的过程，重点检查：
- 功能是否正确（参数、逻辑、返回值）
- 失败时是否返回合理错误信息
- 性能是否满足需求（响应时间）
- 安全性是否合规（鉴权、权限控制）

---

## 2. 接口测试常用工具

**推荐工具（任选其一即可）：**
- Postman（最常用，图形化）
- Apifox（国产，文档 + 测试 + Mock 一体）
- curl（命令行，轻量）

---

## 3. 接口测试必备基础知识

- **HTTP 方法**：GET / POST / PUT / DELETE
- **请求地址**：通常是 `http://域名:端口/路径`
- **请求头（Header）**：常见 `Content-Type: application/json`
- **请求体（Body）**：JSON 格式
- **响应码（Status Code）**：
  - 200：成功
  - 400：参数错误
  - 401：未授权
  - 500：服务器错误

---

## 4. 接口测试的通用流程

### Step 1：准备接口清单
整理出接口的：
- 路径
- 方法
- 必填参数
- 返回结构

### Step 2：发起请求
用工具发送请求，检查：
- 是否成功
- 响应数据是否正确

### Step 3：测试边界与异常
验证异常情况：
- 缺少参数
- 参数格式错误
- 传入非法值

### Step 4：记录结果
写测试记录或保存请求（便于重复测试）

---

## 5. Postman 基础用法（通用）

1. 新建请求
2. 选择方法（GET / POST）
3. 输入 URL
4. 设置 Header：
   - `Content-Type: application/json`
5. 如果是 POST/PUT，设置 Body → raw → JSON
6. 点击 Send
7. 查看 Response

---

## 6. curl 快速测试（通用）

**GET 示例**
```bash
curl "http://localhost:8080/api/xxx"
```

**POST 示例**
```bash
curl -X POST "http://localhost:8080/api/xxx" \
  -H "Content-Type: application/json" \
  -d '{"key":"value"}'
```

---

## 7. 鉴权接口测试思路（通用）

如果接口需要登录：
1. 先调用登录接口获取 Token
2. 后续请求在 Header 加：
   - `Authorization: Bearer <token>`

---

## 8. 常见问题排查

- **404**：路径不对
- **401**：未登录或 token 过期
- **415**：Content-Type 设置错误
- **500**：后端异常（看日志）

- 先测通一个接口，再扩展到多个
