# 时序图

## 1. 用户下单时序图

```mermaid
sequenceDiagram
    autonumber
    actor U as 用户（小程序）
    participant FE as 前端 Pages
    participant API as api/request.js
    participant AUTH as AuthInterceptor
    participant CTRL as OrderController
    participant SVC as OrderService
    participant MP as OrderMapper
    participant DB as MySQL

    U->>FE: 点击服务卡片
    FE->>API: GET /api/service/{id}
    API->>AUTH: 放行（公共路由）
    AUTH->>CTRL: ServiceController.getById()
    CTRL->>SVC: serviceService.getById()
    SVC->>MP: selectById()
    MP->>DB: SELECT * FROM services
    DB-->>MP: Service 实体
    MP-->>SVC: Service
    SVC-->>CTRL: Service
    CTRL-->>API: ApiResponse(data: Service)
    API-->>FE: 服务详情
    FE-->>U: 展示服务详情页

    U->>FE: 填写并提交订单
    FE->>API: POST /api/order/create
    API->>AUTH: 校验 JWT Token
    AUTH->>CTRL: OrderController.create()
    CTRL->>CTRL: 参数校验（@Valid）
    CTRL->>SVC: orderService.create(request)
    SVC->>SVC: 构建 Order 实体
    SVC->>MP: insert(order)
    MP->>DB: INSERT INTO orders
    DB-->>MP: orderId
    MP-->>SVC: 插入成功
    SVC-->>CTRL: Order
    CTRL-->>API: ApiResponse(data: Order)
    API-->>FE: 创建成功
    FE-->>U: 跳转下单成功页
```

## 2. AI 文本问答时序图

```mermaid
sequenceDiagram
    autonumber
    actor U as 用户（小程序）
    participant FE as ai-chat.vue
    participant API as api/request.js
    participant AUTH as AuthInterceptor
    participant CTRL as AiController
    participant SVC as AiService
    participant PROV as IAiProvider<br/>（TencentAiServiceImpl）
    participant EXT as 腾讯混元 API
    participant MP as AiQueryLogMapper
    participant DB as MySQL

    U->>FE: 输入问题并发送
    FE->>API: POST /api/ai/chat<br/>{query, provider: "TENCENT"}
    API->>AUTH: 校验 JWT Token
    AUTH->>CTRL: AiController.chat()
    CTRL->>SVC: aiService.chat(userId, request)
    SVC->>SVC: 根据 provider 选择引擎
    SVC->>PROV: chat(query)
    PROV->>PROV: 构建 TC3-HMAC-SHA256 签名<br/>设置 X-TC-Region: ap-beijing
    PROV->>EXT: POST hunyuan.tencentcloudapi.com
    EXT-->>PROV: JSON {Response: {Choices: [...]}}
    PROV->>PROV: 解析 Choices[0].Message.Content
    PROV-->>SVC: AI 回复文本
    SVC->>MP: insert(AiQueryLog)
    MP->>DB: INSERT INTO ai_query_logs
    DB-->>MP: logId
    SVC-->>CTRL: AI 回复
    CTRL-->>API: ApiResponse(data: 回复文本)
    API-->>FE: 响应
    FE-->>U: 展示 AI 回复 + 语音播报
```
