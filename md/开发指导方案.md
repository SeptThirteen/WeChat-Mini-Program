## 毕业设计版开发路线图

### 第一阶段：需求确定与设计（1-2周）

**1. 功能范围 MVP 版本（重点：可完成性）**
- **滴滴摇人服务**：先做一个服务模块 demo
  - 场景1：家务帮助（定时上门，简单任务）
  - 功能：下单 → 分配 → 完成 → 评价
  
- **公共服务查询**：2-3个常用查询
  - 电费查询（模拟数据）
  - 水费查询（模拟数据）
  - 健康提醒（日期提醒服务）

- **不做的**：语音智能问答（太复杂）、多社区支持（先单社区）

**2. 数据库设计**
```
用户表：user_id, phone, name, age, address
服务表：service_id, category, description, price
订单表：order_id, user_id, service_id, status, created_time
查询记录表：记录用户查询历史
```

**3. 小程序原型**
- 底部3个 tab：服务、查询、我的
- 适老化设计：字号 18px+、高对比度、大按钮

### 第二阶段：后端开发（3-4周）

**技术栈：SpringBoot + MySQL**

1. **项目结构**
```
wechat-elderly-service/
├── src/main/java
│   ├── controller/     # API接口
│   ├── service/        # 业务逻辑
│   ├── mapper/         # 数据库操作（MyBatis Plus）
│   ├── entity/         # 数据模型
│   ├── dto/            # 数据传输对象
│   ├── exception/      # 自定义异常处理
│   └── config/         # 配置文件
├── resources
│   ├── application.yml
│   ├── application-dev.yml
│   └── db/
│       └── init.sql
└── pom.xml
```

2. **核心 API 清单（扩展版）**

| 接口 | 方法 | 权限 | 说明 |
|-----|------|------|------|
| /api/auth/login | POST | 无 | 手机号 + 验证码登录 |
| /api/auth/logout | POST | 用户 | 登出 |
| /api/service/list | GET | 用户 | 服务列表（分类） |
| /api/service/{id} | GET | 用户 | 服务详情 |
| /api/order/create | POST | 用户 | 创建订单 |
| /api/order/list | GET | 用户 | 我的订单（分页） |
| /api/order/{id}/cancel | POST | 用户 | 取消订单 |
| /api/order/{id}/rate | POST | 用户 | 评价订单 |
| /api/bill/query | POST | 用户 | 费用查询 |
| /api/user/profile | GET | 用户 | 个人信息 |
| /api/user/update | PUT | 用户 | 更新个人信息 |
| /api/message/list | GET | 用户 | 消息列表 |

3. **推荐技术栈及配置**
```xml
<!-- Spring Boot 3.x（支持Java 17+） -->
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-web</artifactId>
    <version>3.0.0</version>
</dependency>

<!-- MyBatis Plus（ORM框架） -->
<dependency>
    <groupId>com.baomidou</groupId>
    <artifactId>mybatis-plus-boot-starter</artifactId>
    <version>3.5.3</version>
</dependency>

<!-- MySQL驱动 -->
<dependency>
    <groupId>mysql</groupId>
    <artifactId>mysql-connector-java</artifactId>
    <version>8.0.33</version>
</dependency>

<!-- Lombok简化代码 -->
<dependency>
    <groupId>org.projectlombok</groupId>
    <artifactId>lombok</artifactId>
    <version>1.18.30</version>
</dependency>

<!-- JWT认证 -->
<dependency>
    <groupId>io.jsonwebtoken</groupId>
    <artifactId>jjwt-api</artifactId>
    <version>0.12.3</version>
</dependency>
```

4. **关键实现要点**
- **JWT 认证**：简单的 token 方案，避免复杂 OAuth
- **异常处理**：统一的异常拦截，返回规范的 JSON 响应
- **分页查询**：MyBatis Plus 内置分页拦截器
- **数据校验**：使用 @Valid 注解进行请求参数校验
- **日志记录**：使用 Slf4j + Logback 记录关键操作

### 第三阶段：小程序开发（3-4周）

**技术栈：uni-app + Vue3（可选 Vite）**

1. **项目结构**
```
wechat-elderly-service-mini/
├── pages/
│   ├── index/              # 首页-服务列表
│   ├── service/
│   │   └── detail.vue      # 服务详情
│   ├── order/
│   │   ├── list.vue        # 订单列表
│   │   └── detail.vue      # 订单详情
│   ├── query/
│   │   ├── index.vue       # 查询首页
│   │   └── result.vue      # 查询结果
│   └── user/
│       ├── login.vue       # 登录页
│       ├── profile.vue     # 个人信息
│       └── settings.vue    # 设置页
├── components/             # 全局组件
│   ├── OrderCard.vue
│   ├── ServiceCard.vue
│   └── RateDialog.vue
├── api/                    # API 调用
│   ├── request.js          # 请求拦截器
│   ├── auth.js
│   ├── order.js
│   ├── service.js
│   └── bill.js
├── store/                  # Pinia 状态管理
│   ├── user.js
│   └── app.js
├── styles/                 # 全局样式
│   └── theme.scss          # 适老化设计 token
├── utils/                  # 工具函数
│   ├── format.js           # 格式化函数
│   └── validator.js        # 验证工具
└── App.vue
```

2. **适老化设计标准**
```scss
// 字号规范
$fontSize-base: 18px;      // 基础字号
$fontSize-lg: 24px;        // 标题
$fontSize-md: 20px;        // 按钮、导航
$fontSize-sm: 16px;        // 说明文字

// 颜色对比度（WCAG AA 标准）
$color-primary: #1890ff;
$color-text: #333333;      // 避免黑白对比过强
$color-bg: #f5f5f5;        // 背景要温和

// 按钮尺寸
$btn-height: 56px;         // 便于点击
$btn-width: 80%;           // 宽屏适配
```

3. **核心功能实现**
- **登录模块**：
  - 手机号输入（带输入检验）
  - 验证码（测试环境：任意 6 位数字）
  - 记住登录状态（本地存储 token）
  
- **服务下单流程**：
  - 服务列表页：展示所有服务（图片、名称、价格）
  - 服务详情页：详细描述、图片、评价
  - 下单确认页：确认用户信息、服务内容、价格
  - 订单创建：调用后端 API

- **订单管理**：
  - 订单列表（待接单、进行中、已完成、已取消）
  - 订单详情（服务方信息、进度、聊天入口）
  - 订单评价（星级 + 文字评价）

- **费用查询**：
  - 查询表单（社区 ID、用户 ID、月份）
  - 结果展示（表格形式，数据清晰）
  - 查询历史（便于重复查询）

4. **推荐 UI 库和插件**
```json
{
  "dependencies": {
    "vue": "^3.3.0",
    "pinia": "^2.1.0",
    "uni-app": "^3.0.0"
  },
  "devDependencies": {
    "uview-plus": "^3.1.0",     // uni-app UI库
    "sass": "^1.62.0",
    "vite": "^4.3.0"
  }
}
```

5. **关键实现要点**
- **请求拦截器**：自动添加 token，统一错误处理
- **状态管理**：用户登录信息、app 全局状态用 Pinia
- **本地存储**：使用 uni.setStorageSync 保存 token
- **防抖和节流**：避免重复提交
- **加载状态**：显示 loading 和错误提示

### 开发建议（单人项目优化）

**✅ 优势**
- 有技术基础（Java + 前端），学习曲线不陡
- 时间充足，可以打磨细节
- 单人项目，不用协调，思路清晰

**✅ 推荐流程**
1. **第 1-2 周**：建立后端框架，跑通第一个 API
2. **第 3-4 周**：完成所有后端 API 和数据库
3. **第 5-6 周**：学习 uni-app，建立小程序框架
4. **第 7-9 周**：小程序前端开发和联调
5. **第 10-12 周**：测试、优化、文档、论文
6. **第 13-16 周**：论文迭代和答辩准备

**⚠️ 注意事项**
- **不要完美主义**：功能优先于代码优雅，论文比代码更重要
- **定期提交 Git**：每个功能完成就提交，便于回溯
- **进度记录**：每周写一个进度总结（对写论文很有帮助）
- **尽早联调**：不要等后端全完再做小程序，可以同步进行

**🎯 论文核心竞争力（你有时间做深度）**
- 详细的适老化设计分析（对比市场产品）
- 完整的用户研究（虽然是假设社区，但要科学）
- 系统的性能优化总结
- 可部署的生产级代码（完整度高）
