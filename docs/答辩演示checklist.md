# 答辩演示 Checklist

> 演示前 30 分钟过一遍"预检",演示动线约 8 分钟。每个环节标注了预期结果与翻车预案。

---

## 一、演示前 30 分钟预检

- [ ] 服务器健康:`curl http://<公网IP>:8080/api/health` 返回 ok(手机流量开热点测外网可达)
- [ ] 手机体验版可打开,已开"调试模式"(右上角 ··· → 开发调试),能完成登录
- [ ] 电脑浏览器打开工人端 `http://<公网IP>:8080/worker/index.html` 并登录(王师傅 18000000001 / 123456)
- [ ] 数据库备份已做:`docker compose exec mysql sh -c 'mysqldump ...' > backup.sql`
- [ ] 数据归位:若上次演示留了脏数据,`docker compose down -v && docker compose up -d` 重置(⚠️清库)
- [ ] 备选网络:会场 Wi-Fi 不通时切手机热点(演示机与手机同一网络或用流量调试)
- [ ] 兜底录像:全程操作录屏存本地,现场断网时播放

## 二、演示动线(建议顺序)

| # | 操作 | 预期结果 | 翻车预案 |
|---|------|---------|---------|
| 1 | 登录页输入手机号 → 获取验证码 | 弹窗显示演示验证码(60s 冷却) | 提前 1 分钟先取一次验证码,演示时直接用 |
| 2 | 填验证码登录 | 进入首页(竖排功能列表) | — |
| 3 | 一呼馨家 → 点"上门维修" | 进入下单页,地址已预填 | — |
| 4 | 选今天/时段 → 立即预约 | 下单成功页 | — |
| 5 | 电脑端工人端抢单 | 待抢单列表出现该订单,接单 | 手机端"我的订单"应变为已接单 |
| 6 | 工人端完成订单 → 手机端评价 | 评价成功,详情页显示星级 | — |
| 7 | 一呼馨家 → **语音下单** | 点击说话:"明天上午帮我修水龙头" → 确认卡显示识别结果 → 确认跳预填下单 | **依赖有效 AI Key**,若未配置:现场讲降级逻辑(主备引擎+友好提示),展示代码与单测 |
