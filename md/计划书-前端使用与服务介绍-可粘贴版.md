# 社区适老化服务小程序
## 计划书填充内容（前端使用与服务介绍）

三、产品概况

### 1. 产品技术概况与实现方式（前端视角）
本项目为面向中老年群体的社区综合服务小程序，前端基于 uni-app 构建，支持微信小程序与 H5 双端运行。产品采用“一级入口 + 任务化页面 + 语音辅助”的信息架构，将复杂服务流程拆解为可理解、可操作的步骤。

前端通过统一请求模块与后端接口对接，实现登录鉴权、服务查询、订单流转、便民查询、AI问答等能力。界面采用适老化视觉规范（大字号、高对比、卡片化入口、简化路径），降低学习成本和误操作概率。

### 2. 项目使用说明（用户操作路径）
本项目核心使用路径如下：
1. 用户登录后进入首页，通过三大入口选择服务类型：一呼馨家、公共服务、AI问答。
2. 在“一呼馨家”中选择服务项目，填写预约时间、地址和备注后提交订单，支持单次预约与长期预约。
3. 在“公共服务”中进行社保/医保相关事项办理跳转，或开展水电燃气/有线电视等便民缴费查询。
4. 在“AI问答”中通过语音或文字提问，获取社保、健康、帮扶服务等问题解答。
5. 在“我的”页面统一查看订单、缴费记录、政务代办进度，并维护紧急联系人和常用地址。

该流程实现“从需求发起到结果查询”的闭环服务，减少老年用户在多系统之间反复切换。

### 3. 产品服务介绍（前端可见服务能力）

#### （1）一呼馨家：社区到家帮扶服务
一呼馨家模块提供高频生活帮扶，当前包含四类服务：
- 暖心陪伴（日间照护）
- 贴心出行（外出陪同）
- 跑腿帮买（代购）
- 上门维修（基础维修）

用户可按日期、时间段下单，并补充细分需求。订单提交后可在“我的订单”中持续跟踪状态，支持取消和服务后评价，形成标准化服务闭环。

#### （2）公共服务：政务与民生事项聚合
公共服务模块整合政务办理入口与便民缴费能力，主要包含：
- 社保查询
- 养老补贴申请
- 医保备案
- 电费查询
- 水费查询
- 燃气/有线电视查询

该模块的价值在于将分散在不同平台的事项进行统一聚合，提升中老年用户办理效率。

#### （3）AI问答：低门槛智能咨询服务
AI问答模块支持文字输入、语音输入、常见问题语音播报三种交互方式，覆盖场景包括：
- 社保与政务咨询
- 健康与慢病管理常见问题
- 帮扶服务流程解释与指引

通过语音交互降低输入门槛，提升对视力下降、文字输入不便人群的可达性。

#### （4）个人中心：统一管理与安全关怀
个人中心提供统一账户与服务管理能力，主要包括：
- 个人资料维护
- 常用地址维护
- 缴费记录查看
- 政务代办进度查看
- 一呼馨家订单管理
- 紧急联系人设置

该模块强化“可管理、可回溯、可应急”的服务保障能力，提升用户信任与持续使用意愿。

### 4. 产品价值总结
从前端使用体验看，本项目围绕“看得清、点得准、说得出、查得到”四个目标设计，兼顾功能完整性与老年用户可用性，能够有效提升社区适老服务的触达效率与实际使用率。

四、市场营销

### 1. 目标市场与目标用户
项目主要面向以下用户群体：
- 社区中老年用户（尤其是需要照护、陪同、代办支持的人群）
- 老年用户家属（异地子女、照护责任人）
- 社区居委会及基层服务组织

项目定位为“社区适老化一站式服务入口”，满足高频、刚需、可持续复用的民生场景。

### 2. 用户使用场景与市场落地路径
典型场景包括：
- 就医陪同、日常代购、上门维修等即时帮扶场景
- 社保、医保、补贴等政务咨询与办理引导场景
- 水电燃气等周期性缴费查询场景
- 老人不会打字时的语音咨询与常见问题播报场景

项目通过“高频帮扶 + 高频查询 + 高频咨询”三类入口形成稳定访问习惯，提升留存和复购。

### 3. 市场竞争策略（前端产品侧）
本项目在前端体验上的竞争策略主要体现在：
1. 适老化优先：大字号、卡片入口、步骤简化、语音优先。
2. 一站式聚合：将帮扶、政务、缴费、咨询放在同一产品内，减少切换成本。
3. 闭环可追踪：订单、进度、记录统一沉淀在“我的”页面，提升可管理性。
4. 低门槛交互：语音输入和常见问题播报显著降低使用门槛。

### 4. 渠道与推广建议
结合项目特性，建议采用“社区场景驱动”的推广方式：
- 与社区居委会、街道服务中心联合推广。
- 通过物业、社区卫生服务站设置线下引导点。
- 通过家属转介绍和志愿者教学提升首次激活率。
- 在节假日与民生办理高峰期开展专题活动（如缴费季、体检季）。

### 5. 商业价值与社会价值
项目不仅具备服务撮合和增值服务变现潜力，也具备显著社会价值：
- 提升老年人数字公共服务可及性。
- 降低基层服务组织重复沟通成本。
- 强化社区养老与便民服务协同效率。
- 为后续区域复制和平台化运营提供标准化产品基础。
