# FAQ 音频文件目录

此目录存放常见问题语音播报的 MP3 文件。

## 文件命名规则
- `faq-001.mp3` — 如何查询社保？
- `faq-002.mp3` — 如何预约帮扶服务？
- `faq-003.mp3` — 水电费怎么查询？
- `faq-004.mp3` — 紧急联系人怎么设置？
- `faq-005.mp3` — 订单取消/评价怎么操作？
- `faq-006.mp3` — 政务代办如何申请？

## 录制要求
- 采样率: 16kHz 或以上
- 格式: MP3
- 语速: 适中偏慢（适合老年用户）
- 语言: 普通话
- 时长: 每条 30-90 秒

## 临时方案
在正式录音前，可使用 TTS 工具生成临时音频。
也可在前端 FAQ 面板中降级为文字展示（当音频文件不存在时）。
