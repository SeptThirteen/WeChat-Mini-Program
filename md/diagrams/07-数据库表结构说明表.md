# 数据库表结构说明

## 表 1：users - 用户表

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| user_id | BIGINT | PK, AUTO_INCREMENT | 主键 |
| phone | VARCHAR(20) | NOT NULL | 手机号（登录凭证） |
| name | VARCHAR(50) | NOT NULL | 用户姓名 |
| age | INT | - | 年龄 |
| address | VARCHAR(255) | - | 常用地址 |
| community | VARCHAR(100) | DEFAULT NULL | 绑定社区 |
| created_time | TIMESTAMP | DEFAULT CURRENT_TIMESTAMP | 注册时间 |

## 表 2：services - 服务项目表

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| service_id | BIGINT | PK, AUTO_INCREMENT | 主键 |
| category | VARCHAR(50) | NOT NULL | 服务类别（家务帮助/基础陪护/维修等） |
| description | VARCHAR(255) | NOT NULL | 服务描述 |
| price | DECIMAL(10,2) | NOT NULL | 参考价格（元） |
| display_name | VARCHAR(50) | DEFAULT NULL | 友好名称（面向用户） |
| created_time | TIMESTAMP | DEFAULT CURRENT_TIMESTAMP | 创建时间 |

## 表 3：workers - 服务人员表

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| worker_id | BIGINT | PK, AUTO_INCREMENT | 主键 |
| phone | VARCHAR(20) | NOT NULL, UNIQUE | 手机号（登录凭证） |
| name | VARCHAR(50) | NOT NULL | 姓名 |
| password | VARCHAR(100) | NOT NULL | 密码（当前为明文） |
| category | VARCHAR(20) | DEFAULT '其他' | 人员类别（超市老板/志愿者/社区工作人员/物业工作人员/其他） |
| created_time | TIMESTAMP | DEFAULT CURRENT_TIMESTAMP | 注册时间 |

## 表 4：orders - 订单表

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| order_id | BIGINT | PK, AUTO_INCREMENT | 主键 |
| user_id | BIGINT | NOT NULL, FK -> users.user_id | 下单用户 |
| service_id | BIGINT | NOT NULL, FK -> services.service_id | 关联服务项 |
| service_name | VARCHAR(100) | DEFAULT NULL | 冗余服务名称 |
| scheduled_date | VARCHAR(20) | DEFAULT NULL | 预约日期 |
| scheduled_slot | VARCHAR(30) | DEFAULT NULL | 预约时段 |
| address | VARCHAR(255) | DEFAULT NULL | 服务地址 |
| remark | VARCHAR(500) | DEFAULT NULL | 备注（含细分需求） |
| contact_phone | VARCHAR(20) | DEFAULT NULL | 用户联系电话快照 |
| rating | INT | DEFAULT NULL | 评分（1-5） |
| worker_id | BIGINT | DEFAULT NULL, FK -> workers.worker_id | 接单服务人员 |
| assigned_time | TIMESTAMP | NULL DEFAULT NULL | 接单时间 |
| order_type | VARCHAR(10) | NOT NULL, DEFAULT 'SINGLE' | 订单类型：SINGLE / RECURRING |
| date_start | VARCHAR(20) | DEFAULT NULL | 长期订单开始日期 |
| date_end | VARCHAR(20) | DEFAULT NULL | 长期订单结束日期 |
| recurrence_rule | VARCHAR(50) | DEFAULT NULL | 重复规则（每天/每周/每周一三五等） |
| status | VARCHAR(20) | NOT NULL | 状态：CREATED / ASSIGNED / COMPLETED / RATED / CANCELLED |
| created_time | TIMESTAMP | DEFAULT CURRENT_TIMESTAMP | 创建时间 |

## 表 5：bill_queries - 缴费查询记录表

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| query_id | BIGINT | PK, AUTO_INCREMENT | 主键 |
| user_id | BIGINT | NOT NULL, FK -> users.user_id | 查询用户 |
| query_type | VARCHAR(50) | NOT NULL | 查询类型（electric/water/tv） |
| query_params | VARCHAR(255) | - | 查询参数 |
| result_snapshot | VARCHAR(500) | - | 结果快照（模拟数据） |
| created_time | TIMESTAMP | DEFAULT CURRENT_TIMESTAMP | 查询时间 |

## 表 6：government_tasks - 政务代办表

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| task_id | BIGINT | PK, AUTO_INCREMENT | 主键 |
| user_id | BIGINT | NOT NULL, FK -> users.user_id | 申办用户 |
| task_type | VARCHAR(50) | NOT NULL | 申办类型（养老补贴/医保备案等） |
| task_desc | VARCHAR(255) | DEFAULT NULL | 申办描述 |
| status | VARCHAR(20) | NOT NULL, DEFAULT 'SUBMITTED' | 状态：SUBMITTED / PROCESSING / COMPLETED / REJECTED |
| submitted_time | TIMESTAMP | DEFAULT CURRENT_TIMESTAMP | 提交时间 |
| updated_time | TIMESTAMP | DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP | 更新时间 |

## 表 7：emergency_contacts - 紧急联系人表

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| contact_id | BIGINT | PK, AUTO_INCREMENT | 主键 |
| user_id | BIGINT | NOT NULL, FK -> users.user_id | 所属用户 |
| name | VARCHAR(50) | NOT NULL | 联系人姓名 |
| phone | VARCHAR(20) | NOT NULL | 联系电话 |
| relation | VARCHAR(30) | DEFAULT NULL | 与用户关系（家属/社区服务等） |
| created_time | TIMESTAMP | DEFAULT CURRENT_TIMESTAMP | 创建时间 |

## 表 8：ai_query_logs - AI 问答日志表

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| log_id | BIGINT | PK, AUTO_INCREMENT | 主键 |
| user_id | BIGINT | NOT NULL, FK -> users.user_id | 提问用户 |
| provider | VARCHAR(20) | NOT NULL | AI 引擎（BAIDU / TENCENT） |
| intent | VARCHAR(30) | DEFAULT 'free' | 意图分类（shengbao/health/bangfu/faq/free） |
| query_text | TEXT | NOT NULL | 用户查询文本 |
| response_text | TEXT | - | AI 回复文本 |
| created_time | TIMESTAMP | DEFAULT CURRENT_TIMESTAMP | 记录时间 |

---

## 表关系总览

| 主表 | 从表 | 外键 | 关系 |
|------|------|------|------|
| users | orders | user_id | 1:N（用户 -> 订单） |
| services | orders | service_id | 1:N（服务 -> 订单） |
| workers | orders | worker_id | 1:N（人员 -> 订单） |
| users | bill_queries | user_id | 1:N（用户 -> 查询） |
| users | government_tasks | user_id | 1:N（用户 -> 代办） |
| users | emergency_contacts | user_id | 1:N（用户 -> 联系人） |
| users | ai_query_logs | user_id | 1:N（用户 -> 问答） |
